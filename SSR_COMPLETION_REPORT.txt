 🔄 HOW IT WORKS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Browser makes request
   ↓
2. Express server receives request
   ↓
3. SSR handler generates HTML shell
   ↓
4. Complete HTML sent to browser immediately
   ↓
5. Browser displays content
   ↓
6. JavaScript bundles load in background
   ↓
7. React hydrates (attaches to HTML)
   ↓
8. App becomes fully interactive

Result: Content visible immediately, full interactivity when ready
